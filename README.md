# Python 自动化脚本教学项目

> Python 被称为"胶水语言"，最擅长把各种工具粘在一起做自动化。本项目通过 **14 个模块** 带你学会用 Python 写自动化脚本——重点是**怎么用**，简单讲**底层原理**。

## 适合谁

- 已掌握 Python 基础语法（变量、函数、循环、类）
- 想学会用标准库和第三方库写自动化脚本
- 想理解每个库"为什么这么设计"

## 怎么学

1. **先读模块 README.md**——理解这个库解决什么问题、核心 API 有哪些
2. **再跑示例脚本**——`uv run python lessons/0X_xxx/0Y_脚本.py`，看输出
3. **改一改**——把示例里的路径、参数换成你自己的，观察变化
4. **原理小节**——README 末尾有"底层原理"，简单了解即可，不影响使用

## 设计原则

- **每个脚本可独立运行**：不互相依赖，随时挑一个跑
- **示例用 sample/ 里的测试文件**：不碰你真实文件，安全
- **标准库优先**：能用标准库解决的就不引第三方，并说明为什么
- **UTF-8 编码**：所有文件统一 UTF-8，避免中文乱码
