# 环境准备

本项目用 [uv](https://docs.astral.sh/uv/) 管理 Python 版本和依赖。uv 是一个用 Rust 写的极速包管理器，比 pip 快 10-100 倍。

## 1. 安装 uv

**Windows（PowerShell）：**
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**macOS / Linux：**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

安装后重启终端，确认：
```bash
uv --version
```

> **原理**：uv 把 Python 解释器和包都缓存到统一目录（`~/.local/share/uv/`），不同项目共享同一份包，所以装得快、省空间。它替代了 `pyenv + pip + venv` 三个工具。

## 2. 安装项目依赖

在项目根目录执行：
```bash
uv sync
```

这一条命令会自动：
1. 下载 Python 3.12（如果没装过）
2. 创建虚拟环境（`.venv/`）
3. 安装 `pyproject.toml` 里所有依赖

## 3. 运行示例脚本

**方式一（推荐）：用 uv run**
```bash
uv run python lessons/01_文件批处理/01_pathlib基础.py
```
`uv run` 会自动激活虚拟环境，不用手动 `activate`。

**方式二：手动激活虚拟环境**
```bash
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

python lessons/01_文件批处理/01_pathlib基础.py
```

## 4. 添加新依赖（以后想装别的库时）

```bash
uv add beautifulsoup4    # 加到 dependencies
uv remove beautifulsoup4 # 移除
```

## 5. 常见问题

**Q: `uv sync` 报网络错误？**
设国内镜像：
```bash
export UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple   # macOS/Linux
set UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple      # Windows CMD
```

**Q: 想换 Python 版本？**
改 `.python-version` 文件内容（如改成 `3.11`），再 `uv sync`。

**Q: 脚本里中文乱码？**
本项目所有文件统一 UTF-8。若终端乱码，Windows 上执行 `chcp 65001` 切到 UTF-8 代码页。
